# AHM Studio V8 Design Specification

This project uses the user's supplied `Zack-d-fimls-skill.md` as the production
blueprint. The target is the same high-level category as the uploaded reference:
fast-paced stylized 3D cinematic short-form storytelling.

Core formula:
1. Curiosity-loop script: myth/question -> twist -> mechanism/reveal -> kicker.
2. Consistent characters, props and environments through reference-driven assets.
3. Stylized-realistic cinematic 3D visuals.
4. Green visual annotations for reveals/how-it-works moments.
5. Red annotations/effects for danger, impact and physics.
6. One recognizable narrator voice: the user's own voice clone where supported.
7. Fast cuts, zoom-ins and screen shakes.
8. 9:16 vertical.
9. Large readable subtitles.
10. One complete video, not episodes.

Runtime rule for this AHM project:
- Natural duration, normally around 30-60 seconds.
- May extend beyond 60 seconds when the story needs it.
- Hard maximum: 120 seconds.
- Never add filler just to hit a target.

Important adaptation:
The supplied skill locks particular Higgsfield model names and tools. This starter
does NOT claim those external tools are installed or available here. It preserves
the production logic while exposing the GPU/video and voice providers as adapters.
